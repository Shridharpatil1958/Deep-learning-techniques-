# 📌 Overview

This repository contains practical implementations of **Deep Learning concepts** using **TensorFlow**, **Keras**, and **Python**.

The projects are designed to help learners understand:

* 🧠 Neural Networks
* ⚡ Activation Functions
* 🔧 Optimizers
* 🛡️ Regularization Techniques
* 🖼️ Convolutional Neural Networks (CNNs)

Each notebook includes implementation, training, visualization, and performance analysis.

---

# 🎯 Objectives

* Learn the fundamentals of Deep Learning
* Compare different activation functions
* Analyze optimizer performance
* Prevent overfitting using regularization
* Build image classification models with CNNs
* Visualize training and evaluation results

# 🚀 Installation

## Clone Repository

```bash
git clone https://github.com/Shridharpatil1958/Deep-learning-techniques-.git
cd Deep-learning-techniques-
```

## Create Virtual Environment

### Windows

```bash
python -m venv venv
venv\Scripts\activate
```

### Linux / Mac

```bash
python3 -m venv venv
source venv/bin/activate
```

## Install Dependencies

```bash
pip install -r requirements.txt
```
